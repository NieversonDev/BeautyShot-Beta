# BeautyShot-Beta

BeautyShot Windows beta downloads. Editable source is maintained separately in a private repository.

## User manuals / Manuais do usuário

**Illustrated manual — revision 2.** English and Brazilian Portuguese: 58 pages per PDF, 22 chapters, 29 actual application screenshots and 24 control-reference tables. Covers the workflows and interface used by BeautyShot 82 and 83.

**Manual ilustrado — revisão 2.** Inglês e português brasileiro: 58 páginas por PDF, 22 capítulos, 29 capturas reais do aplicativo e 24 tabelas de controles. Abrange os fluxos e a interface usados pelo BeautyShot 82 e 83.
